How accurate is each imputation method, beside its coverage?

The campaign page reports coverage. Coverage says whether intervals are honest; it does not say whether the imputed values are close to the truth. This page shows accuracy from the same runs: error of each imputed value, interval score, and error of the downstream slope and correlation, and for the discrete traits how often the imputed class is right.

Table: per-value accuracy by sample size and λ

z-RMSE is the root-mean-square error of the pooled imputation (mean of the 20 draws) on masked cells, divided by the trait's SD; lower is better. Bold marks the lowest in each row. Each row pools ρ = 0 and 0.5.

RMSE and bias of the Rubin-pooled estimate against the true value ρ, over datasets. The complete-data row is the same analysis before masking, the floor any imputation method can reach.

Discrete traits: how often the imputed class is right

The discrete part of the campaign (n = 100 and 300, the same datasets): every arm's 20 draws of each missing binary, ordinal and three-class value. freq A and freq B are castor's Mk model, one trait at a time, with flexible rates; the equal-rates column is simulation v1's model. Each row pools ρ = 0 and 0.5.

What this does not cover

The discrete traits are scored at n = 100 and 300 only (section above); n = 1000 is not run for them. BACE at n = 1000 uses 100 datasets per cell (200 elsewhere), and datasets where a BACE fit errored are left out (see the campaign page's failures table). Numbers come from the campaign aggregate (report.json), the same data as the campaign page.
