## 2026-10-08 retrieval-path verification

The [official `megatrees` repository](https://github.com/daijiang/megatrees) documents `get_tree_bird_n100()` as the accessor for the 100-tree bird sample. Its large multi-tree data are GitHub release assets downloaded to a local cache on first use; the package requires internet access for an uncached download and uses `piggyback` for retrieval. The [BirdTree subset tool](https://birdtree.org/subsets/) lets users select a taxon subset, download a zipped tree sample and metadata, and check completion with an email address and job ID. It is limited to 2,500 species. The tool requires the Jetz et al. (2012) citation and asks users to cite BirdTree.org when they use the web tool.

**Recommendation:** keep retrieval user-controlled. For the standard 100-tree bird sample, users can install `megatrees` and run its documented accessor; for a custom species subset, they can use BirdTree's subset tool and then pass the returned tree object to pigauto. Do not add a pigauto-managed downloader for this release. This uses the existing upstream retrieval path and keeps retrieval provenance visible to the analyst. It does not itself grant pigauto redistribution rights for bundled tree objects. At the time of this 2026-10-08 recommendation, G0/G4 were waiting for an explicit maintainer-warranty disposition; that disposition is recorded in the 2026-10-09 recheck below.
