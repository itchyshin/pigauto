## Resolution and policy checks

- **GNN off:** `impute()` and `fit_pigauto()` both default `gnn=FALSE` (`R/impute.R:461`; `R/fit_pigauto.R:398`). `multi_impute()` and `multi_impute_trees()` also default off (`R/multi_impute.R:425`; `R/multi_impute_trees.R:278`). The two intentional benchmark exceptions are `compare_methods(gnn=TRUE)` (`R/evaluate.R:534`) and `simulate_benchmark(gnn=TRUE)` (`R/simulate_benchmark.R`, definition at line 66); the rest of the exported surface has no GNN default-on formals.
- **Automatic posterior MI:** `multi_impute()`'s first `draws_method` choice is `auto`; `match.arg()` selects that default and `.mi_resolve_draws_auto()` selects posterior only when covariates and `species_col` are absent, no multi-proportion group is declared, and trait preprocessing finds every type continuous (`R/multi_impute.R:435-449`, `:913-949`). Otherwise it emits a message and returns conformal prediction-diagnostic draws that `with_imputations()`/`pool_mi()` refuse. Direct `posterior` imposes the same continuous/no-covariate/single-observation restrictions (`R/mi_posterior.R:1154-1199`). In posterior control, the effective default residual covariance prior is `sep`: `.mip_default_control()` uses `c("sep","iw")`, then `.mip_resolve_control()` merges caller overrides and `match.arg()` resolves it (`R/mi_posterior.R:939-961`).
- **Material stale-doc contradiction:** the 2026-10-02 audit doc says `multi_impute()` defaults to conformal and proposes an `auto` default (`docs/dev-log/defaults-audit/2026-10-02-defaults-audit.md`, Decision 1); current source has already implemented `auto`. It also describes the intended posterior auto route as follow-up, which is stale. `multi_impute_trees()` remains a separate diagnostic API with `draws_method=c("mc_dropout","conformal")` and no posterior route (`R/multi_impute_trees.R:277-278`); its `gnn=FALSE` means mc_dropout actually yields baseline posterior draws, per code comment and branch at `R/multi_impute_trees.R:558-563`.
- **Baseline route:** `impute()`, `fit_pigauto()`, and `fit_baseline()` all declare `lambda_mode` with first choice `estimate`, `discrete_lambda` with first choice `estimate`, `joint_solver` with first choice `inhouse`, and `predict_method` with first choice `auto` (`R/impute.R:443-446`; `R/fit_pigauto.R:437-440`; `R/fit_baseline.R:320-328`). `impute()` also defaults `log_transform=TRUE`, `safety_floor=FALSE`, and `phylo_signal_gate=FALSE` (`R/impute.R:438`, `:456-461`). `fit_pigauto()` agrees on the safety and signal-gate defaults (`R/fit_pigauto.R:432-435`). The baseline `auto` route resolves per trait based on eligible validation information and can fall back to per-column; the returned `predict_method_used` and `predict_method_by_trait` are actual outcomes, not merely the request (`R/fit_baseline.R:1289-1334`).
- **`NULL`, `auto`, `...`, wrappers:** fit objects supplied as `NULL` are constructed in `fit_pigauto()`/`impute()`; `predict_method=NULL` is a separate route-replay sentinel in `fit_baseline()` (`R/fit_baseline.R:317-345`). `impute()` passes explicit baseline options into `fit_pigauto()` and leaves additional GNN fit options in `...` (`R/impute.R:640-660`). `multi_impute()` routes posterior before fitting and reports GNN fit options as ignored there (`R/multi_impute.R:452-462`); for conformal/MC-dropout, it forwards `...` through `impute()` (`:477-493`, `:512-528`). `compare_methods()` and `cross_validate()` accept `...` and forward caller overrides into their imputation fits (definitions at `R/evaluate.R:533` and `R/cross_validate.R:41`). These wrappers can therefore expose a default that differs from the downstream direct-fit default: `compare_methods` and `simulate_benchmark` explicitly default GNN on for comparison runs.
- **Saved-fit reconstruction:** `predict.pigauto_fit()` rebuilds legacy models from `model_config`, filling absent architecture fields with compatibility values; absent `use_transformer_blocks` means `FALSE` (legacy stack), while newer dimensions have explicit fallback values (`R/predict_pigauto.R:242-273`). `multi_impute_trees()` replays baseline settings from saved config but uses compatibility defaults for missing fields: `lambda_mode="estimate"`, `discrete_lambda="fixed_1"` for fits predating that setting, `joint_solver="inhouse"`, `predict_method="auto"`, etc. (`R/multi_impute_trees.R:575-596`). Saved models lacking current package version metadata are accepted; version mismatch only messages (`R/save_load.R:96-104`).

## Limits

The executable check verifies small GNN-off fits and saved-fit prediction, but it does not run a posterior chain, train a GNN, benchmark accuracy or coverage, call network-dependent data helpers, or validate rendered help pages. It does not reconstruct a legacy saved GNN model missing architecture fields; the compatibility values above remain source-inspected. The 33-export assertion verifies names and callable resolution, while the full formal table remains a manual source inventory. CRAN checks, real-model MI recovery, and documentation/site verification are separate audit slices.
