The `drmTMB` path names each fixed coefficient by distributional component and term, such as `mu:x` and `sigma:(Intercept)`. The `gllvmTMB_multi` path obtains `tidy(..., effects = "fixed")` from its owning namespace. Both paths require a scalar convergence code of zero and a scalar `pdHess = TRUE`, including when a caller supplies a custom coefficient or tidy extractor. Pooling also rejects nonfinite estimates, invalid standard errors or covariance, missing or aliased terms, and duplicate names. Coefficients with the same terms in different orders are aligned by name.
