## 1. Goal

`impute()` / `fit_pigauto()` with `gnn = FALSE` run the latent multivariate phylogenetic baseline through the whole pigauto pipeline with no GNN and no torch call, plus a production baseline that does not pay the held-out-cell cost of gate calibration, so that "pigauto without the GNN" vs Rphylopars and BACE, and with vs without the GNN, are each a fair test. The simulation campaign is a separate arc (plan section ARC B), not this task.

## 2. Implemented

- `fit_pigauto(gnn = TRUE, baseline_full = NULL)`: when `gnn = FALSE` the function returns before `get_device()` / `torch_manual_seed()`. Calibration runs the existing `calibrate_gates()` with `delta_cal = mu_cal` (the GNN corner degenerates to the baseline), then `r_cal_gnn` is folded into `r_cal_bm`. Conformal scores come from the held-out fit's validation residuals (conf half, as for the GNN arm). Without a validation split the fit is pure baseline (`r_bm = 1`) with no conformal scores. Both paths build the fit through a new shared internal `build_pigauto_fit()`; two blocks were factored into `split_val_cal_conf()` and `compute_safety_floor_means()` with no numeric change.
- `predict.pigauto_fit()`: under `gnn = FALSE` no model is built and `latent_runs` is filled in plain R with the calibrated blend; `baseline_full` is used only in production mode (no `baseline_override`, no `.mask_observed_idx`), the held-out `baseline` otherwise; MI draws are BM-posterior draws with the caller's RNG state restored; observed cells are not overwritten in `latent_runs` (parity with the GNN arm).
- `impute(gnn = TRUE)`: computes `baseline_full` (`splits = NULL`) before `graph$D` is freed, skips the CUDA reclaim calls, and skips the preflight torch device probe (`.check_pigauto_internal(probe_runtime = FALSE)`).
- `multi_impute(gnn = TRUE)`: `draws_method = "mc_dropout"` under `gnn = FALSE` means BM-posterior draws; one message, no error.
- `multi_impute_trees(gnn = TRUE)`: per-tree baseline fit without held-out cells under `gnn = FALSE`; the per-tree baseline replay now also carries `joint_solver`, `predict_method`, `joint_refine_iter` (pre-existing omission, now load-bearing).
- `fit_baseline()` returns `path`: which dispatch produced each trait's baseline.
- `print()` / `summary()` show `GNN: off (baseline only)`; `plot(fit, "history")` explains the empty history; `gnn` is validated as a single TRUE/FALSE; user covariates under `gnn = FALSE` warn that they are ignored.
- Docs: NEWS entry; AGENTS.md subsection "GNN-off arm"; roxygen on every changed export.
- Tests: `tests/testthat/test-gnn-off.R`, 15 tests, 73 expectations (count = `sum(passed)` from `testthat::test_file(reporter = "silent")`).

## 3a. Decisions and Rejected Alternatives

- D1, kept GNN-on's safety machinery under `gnn = FALSE` (Rose's plan review): a pure BM arm would lose low-signal traits to the grand-mean corner rather than to the GNN, confounding the with/without test. The pure traditional-statistics arm is reachable with existing arguments: `gnn = FALSE, safety_floor = FALSE, phylo_signal_gate = FALSE`. Rejected: `gnn = FALSE` meaning `r_bm = 1` always.
- D2, two baselines rather than one refit in `fit$baseline` (Rose's plan review): four scorers read `fit$baseline` directly, so a refit stored there would be scored on cells it saw. `fit$baseline_full` is read by exactly one consumer, `predict()` in production mode. Rejected: a single tax-free baseline; rejected: a "test-only masked" intermediate.
- Observed cells are not overwritten in `latent_runs` under `gnn = FALSE`, matching the GNN arm's raw-blend storage (the contract's first wording said otherwise; corrected mid-run).
- The preflight torch device probe is skipped under `gnn = FALSE` so that "no torch call" is literally true for `impute()` and `multi_impute_trees()`.
- `mc_dropout` under `gnn = FALSE` is a message, not an error, because `multi_impute_trees()` defaults to it.

## 6. Tests of the Tests

- The zero-torch assertions use a `trace()` counter on `torch::torch_tensor` that is known to fire on the GNN path: the replacement test 10 asserts the counter is greater than 0 for a `gnn = TRUE` predict, and it passed, so a hidden torch call on the GNN-off path would be counted.
- G-S2's model-construction counter was first written as `trace(ResidualPhyloDAE)`, which cannot attach to an `nn_module` generator under `Rscript`; it was replaced by a namespace shim wrapping the generator, and the gate passed with the counter at 0 while the same shim counts 1 on a GNN-on predict.
- The leakage test asserts `baseline$mu` and `baseline_full$mu` differ at test cells before asserting `evaluate()` equality on the pure arm, so an implementation that scored `baseline_full` would fail the equality on non-identical inputs.
- Rose (V2) named test 10 as vacuous (it compared nothing); it was replaced. Two S4 assertions that would have been tautological under the first contract wording (observed-cell overwrite) were confirmed absent.
