## 4. Findings

Full technical detail: `docs/dev-log/arc/2026-08-15-p0-onto-main-arc-notes.md`.

- **F1 `seed` default.** `main` deliberately changed `calibrate_gates(seed = 1L → NULL)` per a
  CRAN reviewer correction, and added `is.null(seed)` guards P0 never saw. Because P0 only
  reformatted the signature, **main's guard code auto-merged silently** — taking P0's side would
  have paired code written for `NULL` with a default that is never `NULL`. Resolved to `main`.
  Scope stated precisely: `impute()`/`multi_impute()` public seeds auto-merged and were never at
  risk; the consequence of the wrong call would have been an inconsistent package, not a
  production behaviour change (`fit_pigauto.R:956` passes `seed` explicitly).
- **F2 NEWS.md placement — an error made and caught.** The first union filed P0's four
  never-released fixes under `# pigauto 0.10.0`, i.e. inside the released CRAN tarball.
  Corrected to `0.10.0.9000 (development)`.
- **F3 AGENTS.md.** P0 predates PR #136 and would have reintroduced a `~/.Codex/projects/…`
  path that never existed. Kept P0's LOAD-FIRST manifest; dropped the two defects #136 removed.
- **F5 the blocker.** See §3 and the arc notes.
- **F4 / F6 pre-existing, not introduced:** `fit_pigauto.R` roxygen shows `seed = 1)` in an
  example while the default is `NULL`; `test-safety-floor.R` ends with a stray top-level
  `skip_if_no_libtorch()`. Both already on `main`. Flagged, not fixed.

## 5. Claim-gate (Rung 2)

`docs/dev-log/arc/2026-08-15-p0-claim-gate-findings.md` — 1 BLOCKING, 5 SHOULD-FIX, 3 NOTE.

**BLOCKING, verified independently against the code:** `vignettes/gnn-architecture.Rmd` §5 tells
users `pred$se` is *"Exact under BM, model-dependent."* On `main`, the default multi-trait path's
SE is:

```r
se[miss_idx_local] <- sqrt(max(sigma2, eps))   # sigma2 <- var(y[obs_idx_local])
```

One scalar broadcast to every missing tip; no phylogenetic position enters it. `main`'s own
comment concedes it (*"Conservative se: empirical sd of observed values"*). P0 replaces it with
per-tip `σ√v_i`, `v_i = diag(Q_no_no⁻¹)`, and its comment names the stake: *"Do not recycle a
single empirical SD — binary threshold decode consumes se."* So pre-fix this also degrades
**predicted binary/ordinal probabilities**, not just interval widths.

**`main` currently ships a documented guarantee its code does not satisfy, and P0 is the fix.**
That raises the value of landing P0 — it does not lower the bar for landing it safely.

## 7b. Durable outcome — GitHub issue #157

The lane's most reusable result is not the merge. Follow-up experiments (recorded in the arc
notes as F5-RESULT / F5-MECHANISM / F5-CONTROL) traced the blocker to a **calibration-vs-predict
delta-surface asymmetry that exists on `main` today, independent of P0**: `calibrate_gates()`
scores a surface where held-out cells start at the baseline and are unpinned, while `predict()`
pins those cells to their own truth. The gate is chosen on one surface and applied to another,
so the val-floor safety property is not enforced on the surface users receive.

Filed as **[#157](https://github.com/itchyshin/pigauto/issues/157)** (2026-08-15), scoped to the
defect alone — P0 is explicitly not proposed for merge there. Reproduction scripts:
`docs/dev-log/arc/2026-08-15-{delta-surface-compare,gate-open-check-on-main}.R`.

This survives whatever is eventually decided about P0.
