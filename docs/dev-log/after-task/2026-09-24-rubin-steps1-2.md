## 2. Implemented

- `script/rubin_lib.R`: Rubin pooling with Barnard-Rubin df (`rubin_pool`), per-cell intervals with
  W = 0 (`rubin_cell_intervals`), PGLS slope under Pagel's lambda with a bounded REML profile fallback
  (`est_pgls_slope`), GLS-whitened phylogenetic correlation (`est_phylo_cor`), Fisher-z pooling (`pool_cor`).
- `script/rubin_freq.R`: freq A, parametric bootstrap then joint conditional draw; freq B, joint conditional
  draws at one fixed Rphylopars-lambda fit.
- `script/rubin_bace.R`: BACE as shipped (n_final = M); BACE plus a post hoc residual draw.
- `script/rubin_cell.R`: one-cell runner with per-arm seeds, per-arm guarded scoring, a complete-data
  reference row, resume-skip and provenance.
- `script/rubin_checks.R`: gates G-S4a and G-S4b. `script/rubin_prerun_totoro.sh`: pre-run launcher (dry
  run by default; checks memory, the 150-core cap across this user's lanes, the BACE build and the code).
- Seven test files in `script/tests-rubin/`.
- Docs: a pre-run plan, a statistics review (Meng), two dated correction notes in the lane plan.

## 3a. Decisions and Rejected Alternatives

- Freq B uses joint conditional draws at the fixed fit, not independent per-cell `N(pred, anc_var)` draws
  (Shinichi, planning). Per-cell draws would also discard the c1-c2 link in co-missing species.
- Coverage is scored against the population value rho; in this DGP the true slope and the true phylogenetic
  correlation both equal rho (derived from `sim_latents`, confirmed by Meng). Scoring against the
  complete-data estimate was rejected because it over-covers by construction.
- The correlation is GLS-whitened on Fisher's z with a normal reference; a tip-level Pearson correlation was
  rejected (its 1/(n-3) variance is wrong under phylogeny).
- The runner defaults to v1's core options (`--driver`, fixed thresholds) so results sit beside v1's.
- A standalone pooler was written instead of calling `R/pool_mi.R` (leased by another lane); `mice::pool`
  is the test oracle.
- The D-280 head-to-head was skipped for this plan (Shinichi).
