# Frozen analysis targets and generator alignment

The production scenario manifest has 151 configurations and 32,240 independent dataset attempts. Each attempt has a deterministic identity seed. Actual posterior generator and sampler seeds are retained separately because the existing posterior generator defines its own seed mapping. Generated data and masks are shared across methods within each attempt.

## Analysis-aware inference

For independent observations, x_i and z_i are independent N(0,1). Exactly x is incomplete. The target is the coefficient of x, beta_x = 0.7, defined before simulation.

For lm, y_i = 0.5 + 0.7 x_i + 0.3 z_i + epsilon_i, with independent epsilon_i distributed N(0,1). The complete-data and imputed-data analysis is y ~ x + z.

For binomial-logit glm, y_i is Bernoulli with logit probability 0.5 + 0.7 x_i + 0.3 z_i. Both analyses use y ~ x + z and the binomial logit link.

For lmer, y_ig = 0.5 + 0.7 x_ig + 0.3 z_ig + b_g + epsilon_ig, with independent b_g distributed N(0,0.5^2) and epsilon_ig distributed N(0,1). There are five observations per group, with 20 or 60 groups. Both analyses use y ~ x + z + (1 | group), REML = FALSE. Intervals use the recorded normal approximation.

MCAR hides a random 30% of x values. MAR has logit missingness a + scale(y) + 0.5 scale(z), where a solves an expected missing fraction of 0.3. The realised MAR fraction varies by replicate. Outcome and z remain observed. This is observed-variable MAR, not missingness driven by hidden x.

The implementation is validation_analysis_dgp() in runners.R. The adapter calls the supported public multi_impute_analysis() with m = 50, missing = x, and no duplicated formula variables as auxiliary predictors. Complete-data fits are retained and assessed against the same independently specified truth. Complete-data estimates do not define truth.

## Other generators

Prediction configurations are drawn directly from campaign_sim_design.R and generated by campaign_gnn_off_lib.R::make_cell(). Named MAR configurations include the fully observed d1 driver required by that generator. Low-signal additions cross lambda 0 and 0.1 with n 100 and 300 and correlation 0 and 0.5.

Family and repeated-observation scenarios use the existing source drivers identified in runners.R settings. The posterior eight-regime manifest is read from script/mi_gls/regimes.R. Regime identifiers, independently defined slope target, actual seeds and analysis covariance choice are retained in every result. Historical sensitivity results are not promoted to refreshed inference evidence.

BIEN uses a fixed 300-species subset selected with seed 20261018 from matched species having at least two finite traits. Masking and scoring use originally observed cells only. This does NOT cover full BIEN scaling, nor does it assert that missing cache values are truth.

## Assessment

Inferential assessment bands are coverage 0.925 to 0.975, mean reported SE divided by empirical SD 0.9 to 1.1, and absolute bias divided by empirical SD at most 0.1. Summaries report Monte Carlo uncertainty across independent datasets. Cell intervals and predictions are first reduced within each dataset. Insufficient precision is indeterminate. Nonconvergence, unavailable metrics and missing attempts remain visible. One pilot replicate cannot establish calibration.
