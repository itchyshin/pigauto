## Explicit deviations and evidence handling

The pilot was frozen before later review corrections. Its raw records keep the original source identity. Corrected summaries retain their own evaluator hashes and never rewrite raw identities. These corrections fix summary applicability, pair reporting and input/provenance controls. MAR constructor changes affect a route not selected in that pilot; a separate actual MAR fit passed. Older posterior cell-interval metrics lack requested-cell denominators and remain unavailable for supported interval claims. New production records must carry the strict denominator schema.

The prediction comparator roster is deliberately narrow: current-default GNN-off and mean/mode controls, with the optional Rphylopars arm disabled. Dedicated covariate scenarios exercise GNN contrasts. A broader historical competitor study is outside this implementation.

The corrected follow-up accounts for seventeen successful full-setting attempts, including all twelve analysis cells, tree, AVONET, BIEN, posterior replay and MAR. Original failed attempts remain retained. The production run completed in 6:12:02. Its first summariser exited with an error after the compute stage because it rejected mixed installed-package inventory hashes. The corrected evaluator re-read the raw records and regenerated all summary tables; raw results were not modified. Its first runtime audit left package-matrix row counts blank, so a matrix fixture was added and the tables regenerated again.

A manifest row or successful pilot is not scientific validation. The production run has 32,240 unique job records and 1,122,060 result rows. Independent review matched job identities, verified per-key summary counts, and reimplemented the assessment classification. The runner-contract roster expects 5,697 scenario/method/estimand groups across all 1,122,060 planned job-level keys; all are present, with zero absent, partial, unexpected or unrostered rows. The 504 planned calibration-bin and posterior-interval groups have zero missing or failed groups; 16,400 GNN-off ordinal calibration-bin records are explicitly unavailable. Payload checks reject invalid statuses, ranges, counts and widths. A fresh Totoro BIEN roster derivation matches its retained source roster, while independent regeneration of all 4,000 posterior DGP cells matches 8,000 saved x/y interval denominators. Ordinal Brier metrics are explicitly unavailable, as are 82 ordinal ECE keys; control-arm interval metrics are also explicitly unavailable. Independent follow-up review passed the corrected validators and source-roster binding.
